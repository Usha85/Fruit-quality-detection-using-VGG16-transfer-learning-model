# 🍎 Fruit Quality Detection using VGG16

## 📌 Project Overview
This project uses deep learning and transfer learning with the VGG16 model to classify fruit quality based on images. The aim is to automate quality detection in agriculture and food industries.

## 🎯 Objectives
- Classify fruits based on quality
- Improve accuracy using transfer learning
- Build an efficient image classification model

## 🛠️ Technologies Used
- Python
- TensorFlow / Keras
- VGG16 (Transfer Learning)
- Jupyter Notebook

## 📂 Dataset
- Image dataset of fruits
- zip files contains the dataset for train, test and valid to train the model
- Categories: Fresh / Rotten 

## ⚙️ Methodology
- Data preprocessing and augmentation
- Transfer learning using VGG16
- Model training and validation
- Performance evaluation

## 📊 Model Performance
- Achieved high accuracy in classification
- Reduced training time using pretrained model

## 📈 Key Features
- Automated fruit quality detection
- Scalable for real-world applications
- Efficient use of deep learning

## 📌 Outcome
Successfully built a model that can classify fruit quality with good accuracy, helping reduce manual inspection.

## 🚀 Future Scope
- Deploy as a web/mobile application
- Use real-time camera input
- Expand dataset for better accuracy
